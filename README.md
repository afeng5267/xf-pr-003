# ✈️ 飞行器大战 (Aircraft Battle)

一个基于 HTML5 Canvas 的经典飞行射击小游戏。

## 🎮 玩法

1. 用浏览器打开 `index.html` 即可开始游戏
2. **移动**：`← → ↑ ↓` 或 `WASD`
3. **射击**：`空格键`
4. 击落敌机得分，躲避敌机子弹和碰撞

## ✨ 特性

- 三种敌机类型（小型/中型/大型），不同血量和分值
- 粒子爆炸特效
- 滚动星空背景
- 关卡递进系统（每 500 分升一级，敌机变快变多）
- 3 条生命，受伤后短暂无敌闪烁
- 双发子弹系统
